# FlowTech – Módulo Cliente
Este projeto diz respeito ao módulo `Cliente` desenvolvido para o projeto de Pesquisa e Inovação do curso de Ciência da Computação no segundo semestre na SPTech.

### O que o Cliente faz?
R: O script simula o monitoramento de hardware de um servidor embarcado utilizado no pórtico de um pedágio eletrônico do modelo Free Flow. Além do monitoramento de hardware, o cliente gera logs e envia as capturas para um Datalake construído sob o ecossistema AWS usando o recurso S3.
